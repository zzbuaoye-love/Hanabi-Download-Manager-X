# 项目概览

Hanabi Download Manager X（HDMX）是一个使用 Flutter 构建的 Windows 桌面下载管理器，重点关注多线程下载、断点续传、清晰的任务状态展示和现代化桌面体验。

当前版本由 **双下载内核**（NSFX + NeoNSF）驱动，并带有一套 **进程隔离的插件系统**，可以通过插件扩展下载协议、设置页和侧边栏页面。

## 平台支持

| 项目 | 说明 |
| --- | --- |
| 目标系统 | Windows 10 / 11 x64 |
| 其他系统 | 暂无适配预期 |
| 已知差异 | Win10 与 Win11 的窗口特效、圆角 API 存在差异，部分效果在 Win10 上使用自定义裁切实现 |

圆角、窗口特效和托盘行为都围绕 Windows 桌面环境做了适配。遇到异常请提交 [Issue](https://github.com/buaoyezz/Hanabi-Download-Manager-X/issues)。

## 核心特性

### 下载能力

| 能力 | 说明 |
| --- | --- |
| 多线程分段 | 可配置线程数与分段数，支持动态分段 |
| 断点续传 | 分段进度、ETag / Last-Modified 持久化，重启后可恢复 |
| 限速 | 分段限速与全局限速独立配置 |
| 连接控制 | 全局连接上限、最大同时下载任务数 |
| 协议策略 | HTTP/1.1、HTTP/2、HTTP/3 版本策略选择 |
| 代理 | 系统代理、显式 HTTP / SOCKS 代理 |
| 请求定制 | 自定义 Header、Cookie、Referer、User-Agent |
| TLS | 可选允许不安全 TLS（默认开启校验） |

### 内核

双内核架构，NSFX / NeoNSF / Auto 三种模式，任务创建后绑定内核不做运行中迁移。详见[下载内核](DOWNLOAD_KERNEL_CN.md)。

### 插件系统

进程隔离的 JSON-RPC 插件，可用任意语言编写，支持下载协议扩展、声明式设置页与侧边栏、插件市场与签名校验。详见[插件开发文档](plugin/README_CN.md)。

### 浏览器集成

| 能力 | 说明 |
| --- | --- |
| 扩展桥接 | Chrome / Firefox 扩展通过本地 HTTP 接口接管下载，默认端口 `6800` |
| 下载弹窗 | 浏览器触发下载时弹出独立窗口确认，可关闭 |
| 剪贴板监听 | 检测剪贴板中的下载链接 |

### 桌面体验

| 能力 | 说明 |
| --- | --- |
| 窗口特效 | Mica、Mica Alt、亚克力、模糊；亚克力可调透明度 |
| 窗口圆角 | 可开关，Win10 与 Win11 亚克力 / 模糊模式使用自定义裁切 |
| 拖动优化 | 可选拖动窗口时临时禁用特效，避免卡顿 |
| 托盘 | 托盘菜单可显示窗口、切换内核、退出；关闭按钮行为可配置为最小化或退出 |
| 窗口状态 | 记忆窗口大小；支持 UI 缩放与字体设置 |
| 主题 | 明暗主题、经典控件视觉开关 |

### 其他

| 能力 | 说明 |
| --- | --- |
| 本地化 | 内置中英双语，支持从 `~/.hdmx/lang/` 加载外部语言包（`.json` / `.arb`） |
| 应用内公告 | 拉取服务端公告并在应用内展示 |
| 性能监视器 | 实时查看资源占用与下载吞吐 |
| 崩溃报告 | Windows 原生崩溃报告器 |
| 首次启动引导 | OOBE 引导流程 |
| 日志管理 | 日志留存天数可配置，默认 7 天 |
| 匿名在线统计 | 可在设置中关闭 |
| 自动更新 | C# NativeAOT + Avalonia 独立更新器，详见[更新器构建](UPDATER_BUILD_CN.md) |

## 数据目录

应用数据统一位于 `~/.hdmx/`：

```text
~/.hdmx/
├── config/                  # 配置
├── data/                    # 应用数据
├── cache/                   # 缓存
├── lang/                    # 外部语言包
├── plugins/                 # 已安装插件与运行日志
│   └── logs/<pluginId>/runtime.log
└── kernel/
    └── neo_nsf/             # NeoNSF 内核独立任务存储
```
